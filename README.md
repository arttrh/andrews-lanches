# Andrews Lanches Artesanais

Site estático com HTML, CSS, JavaScript e GSAP (SplitText e ScrollTrigger).

## Rodar localmente

```sh
python3 -m http.server 8000 --directory dist
```

## Vercel

Importe este repositório. Framework: Other. Output Directory: dist. Não há etapa de build nem instalação.

As imagens estão incluídas em dist/assets. Os contatos levam ao Instagram da loja.
